Recent work is already live. The eeprep-resume skill lets a coding agent write and review a resume using the rules on the resume page. The walkthrough page links five finished resumes for Alex Doe, from a first-year resume to a packed page. The resume-generator tool now writes a separate PDF for each JSON file. The [[Company list|company list page]] is up, built from [company-lists](https://github.com/edwardasilva/company-lists). The list now covers metros in Colorado, Texas, California, and Northern Virginia, plus major employers in all 50 states. The [contribution guide](https://github.com/edwardasilva/eeprep/blob/main/.github/CONTRIBUTING.md#changelog) lists the changes in the companion repositories.
