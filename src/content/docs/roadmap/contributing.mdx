[eeprep](https://github.com/edwardasilva/eeprep) is open source. If you hire electrical engineers or computer scientists, or work as one, you can correct what these pages get wrong.

## Suggest an idea or a fix

Open an [issue](https://github.com/edwardasilva/eeprep/issues/new/choose) and pick a template. Name the page, say what you would change, and say why. Link a public source when you can. Every claim on the site needs a real public source. A claim that can't be backed up stays off the site.

## Edit a page

Fork the repo, edit one page or one fix, and open a pull request into `main`. Guide pages live in `src/content/docs`. Outside links also need an entry in `src/content/references.bib`. The [contribution guide](https://github.com/edwardasilva/eeprep/blob/main/.github/CONTRIBUTING.md) has the local checks.

## Conduct

Be kind and assume good intent. To report a problem with someone's behavior, use GitHub's Report content feature or message the repository owner in private.

For a security problem, follow the [security policy](https://github.com/edwardasilva/eeprep/blob/main/.github/SECURITY.md). Do not open a public issue.
