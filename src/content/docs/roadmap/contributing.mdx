[eeprep](https://github.com/edwardasilva/eeprep) is open source. If you hire electrical engineers or computer scientists, or work as one, you can correct what these pages get wrong.

## Suggest an idea or a fix

Open an [issue](https://github.com/edwardasilva/eeprep/issues/new/choose) and describe what you would change. A short description is all it needs. Naming the page and linking a public source help when you can. Every claim on the site needs a real public source, and maintainers check that during review.

## Edit a page

Fork the repo, edit one page or one fix, and open a pull request into `main` with a short description of what changed and why. That is all a pull request needs, and maintainers review the change. Guide pages live in `src/content/docs`. The [contribution guide](https://github.com/edwardasilva/eeprep/blob/main/.github/CONTRIBUTING.md) has the optional local checks.

## Conduct

Be kind and assume good intent. To report a problem with someone's behavior, use GitHub's Report content feature or message the repository owner in private.

For a security problem, follow the [security policy](https://github.com/edwardasilva/eeprep/blob/main/.github/SECURITY.md). Do not open a public issue.
