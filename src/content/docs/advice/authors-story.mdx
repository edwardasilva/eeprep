eeprep is written by an electrical engineering graduate who now writes embedded software. The advice came out of one ordinary path: a switch from computer science to electrical engineering, a co-op that showed which work did not fit, an internship that showed which work did, and a fall of applications that went nowhere until the method changed.

## What that path taught

Each lesson has its own page on the site.

- A finished project you can defend opens the first door. The [[Projects|Projects page]] covers it.
- One clean page in a standard template gets read. The [[Resume|Resume page]] covers it.
- If 20 applications bring zero interviews, change the resume or the channel. The [[Getting hired|Getting hired page]] covers it.
- A referral beats a cold application. The [[Networking|Networking page]] covers it.
- Interviewers go as deep as you let them, so know every line and never bluff. The [[How to interview|How to interview page]] covers it.

Everything else on the site comes from a linked source. Where a page gives the author's own view, it says so.
