A portfolio is a page per project with a photo, a measured result, and the files. It does not replace the resume, and most screeners never click the link. It pays off later, when a hiring manager wants to see the work behind a bullet. Keep it small, keep every link alive, and put the same three projects on LinkedIn.

## What a reviewer does with the link

Expect the first screener to skip it. [[Resume#How a resume gets read]] shows how many seconds a page gets. The link gets clicked later, by a hiring manager or an interviewer, and then it has to work. [One hiring manager who reads hundreds of resumes sees dead GitHub and LinkedIn links all the time](https://www.reddit.com/r/EngineeringResumes/comments/1hw10ms/12_yoe_some_long_direct_advice_in_tech_from_a/). A dead link costs more than no link.

The portfolio helps most when you have no internship. [An EE graduate with no work experience who got an offer in February 2026 kept a separate project portfolio that showed the projects in depth](https://www.reddit.com/r/EngineeringResumes/comments/1r4c3rv/0_yoe_i_received_an_offer_recently_i_graduated/), with a web version where possible. The resume gave each project one line, and the portfolio held the rest.

## One page per project

<ProjectPageFigure />

The order comes from [the student project sites in Cornell's ECE 4760](https://people.ece.cornell.edu/land/courses/ece4760/FinalProjects/s2004/mx23/myweb/index.htm), which run from the design to the results and keep the code, schematics, and part lists in appendices. Lead with the result line from your resume, then the photo. [One guide to embedded portfolios says to export the schematic and layout as images](https://slategit.com/blog/embedded-firmware-engineer-portfolio-hardware-projects), because readers cannot open the design files, and to include a logic analyzer trace, a scope screenshot, or a terminal log as evidence that the thing works. End with what broke. The bug you found and fixed is the part an interviewer asks about. [[How to interview#Your projects, line by line]] lists the questions.

Put the code and the design files in one GitHub repository per project, with a README that repeats the result line. [[Software#Show it on GitHub]] covers the README and pinned repositories. The portfolio page links to the repository instead of duplicating it.

Three projects are enough. Pick the ones you can defend. [[Projects]] covers how to choose them.

## Hosting for free

Every host below is free for a static site of a few pages and compressed images.

- [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) serves a site straight from a repository. The published site may be no larger than 1 GB, and it has a soft bandwidth limit of 100 GB a month. The repository and the site live together, so a reader can see the commit history.
- [Cloudflare Pages](https://developers.cloudflare.com/pages/platform/limits) gives the free plan 500 builds a month and one build at a time.
- [Vercel's Hobby plan](https://vercel.com/docs/plans/hobby-plan) includes 100 GB of data transfer and is limited to non-commercial, personal use. A student portfolio qualifies.

Plain HTML is fine. If you want a generator, Astro or Hugo builds the pages from Markdown. Do not spend a weekend on the design. Spend it on the project pages.

## LinkedIn

A recruiter's search finds the words in your profile, so the profile is where your resume lines get found. Three rules:

1. Write a headline with the job you want and one specific, such as "EE student, embedded firmware and test automation, graduating 2027", not "Student at University".
2. Put the same project bullets in Projects, with the measured number and a link to the portfolio page. [Georgia Tech's career center says to use industry keywords in the profile and a professional photo](https://www.cc.gatech.edu/sites/default/files/documents/2024/Networking-Tips-Word-Doc.docx).
3. Turn on Open to Work for recruiters only while you search. [LinkedIn says that setting shows your status to people using LinkedIn Recruiter, and that it tries to hide it from recruiters at your current employer but cannot promise complete privacy](https://www.linkedin.com/help/linkedin/answer/a507508/let-recruiters-know-you-re-open-to-work?lang=en).

Your school's career center has a LinkedIn guide. [Berkeley's](https://career.berkeley.edu/prepare-for-success/networking/using-linkedin/) and [MIT's](https://capd.mit.edu/resources/linkedin/) are public. Use LinkedIn for people, too. [[Networking#LinkedIn]] covers the alumni tab.

## Keep it current

Before each application season, open every link on the resume, the portfolio, and the profile. Fix or remove each dead one. Update the result line when a project moves. If a project is dead and you cannot explain it line by line, take the page down.
